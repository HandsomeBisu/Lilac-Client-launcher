# 런처 배경

- 파일: `src/assets/forest-dusk.png`
- 제작: 내장 image_gen 도구로 신규 생성.
- 역할: 전체 화면 배경 전용. 글자·로고·버튼은 HTML로 별도 표시한다.
- 실제 Minecraft 게임 화면을 촬영한 스크린샷이 아니라 생성 이미지다.
- 사용자가 제공한 런처 이미지는 화면 배치와 명암 참고용이며, 해당 앱의 로고·계정·접속자 정보는 사용하지 않았다.

## 최종 프롬프트

Use case: stylized-concept. Asset type: full-window background image for a Minecraft desktop launcher. Generate only the background, absolutely no UI, text, lettering, watermarks, symbols, or logos. Wide 16:9 landscape, 1920x1080 or similar. Style: believable Minecraft Java gameplay screenshot with subtle shader lighting, exact crisp block / voxel geometry and low resolution pixel textures, not smooth illustration or painterly concept art. Scene: a forest clearing at dusk, grassy blocks and a small rustic oak and cobblestone house to the middle-right, dense oak and birch trees at far right, a few lilac flowering plants, warm amber windows. Camera at player eye level looking into scene. Foreground shadowy grass, dark trees frame the right; upper sky visible muted blue-green twilight. The left 45 percent should be a quiet shadowed hillside / woodland with low contrast and no prominent objects, reserved for overlay text. Keep readable visual texture and depth across right half, but no bright overexposed sky. Cozy natural atmosphere, subdued dark greens and warm brown tones, slight violet twilight in shadows. No characters, no people, no mobs, no enormous mountains, no epic fantasy, no purple fog, no bloom overload. This will be dimmed by a dark UI overlay, so retain image details and natural colors.
